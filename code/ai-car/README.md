# 딥러닝 자율주행 자동차 — 코드

무인이동체실습 수업에서 Raspberry Pi 4B 자동차에 쓴 코드입니다.

## 직접 작성한 과제 코드

| 파일 | 내용 |
|---|---|
| `line_recovery.py` | 라인 이탈 감지 + 3단계 복구 최종 버전 (직전 방향 유지 0.25초 → 회전 탐색 3초까지 → 정지, `last_turn`으로 직진 중 이탈에도 탐색) |
| `line_recovery_v1.py` | 1차 버전. 2초가 지나면 후진했고 회전 탐색 분기가 없었음 (`count=+1` 버그 포함, 기록용) |
